# 🚀 AI Tweet Generator

An AI-powered web application that generates **10 on-brand tweets** based on brand details such as industry, campaign objective, and products.  
This tool helps brands quickly create engaging social media content aligned with their communication style.

---

## ✨ Features

🎯 **Brand Voice Analysis**  
- Identifies tone and communication style of a brand.

📝 **Tweet Generation**  
- Automatically generates **10 tweets** in the brand’s voice.

📊 **Content Variety**  
- Mix of engaging, promotional, witty, and informative tweets.

🌐 **Simple Web Interface**  
- Easy-to-use form to input brand details.

⚡ **Fast and Lightweight**  
- Built with Flask for quick execution.
